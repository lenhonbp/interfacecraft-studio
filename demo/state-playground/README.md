# State Playground

Open `index.html` directly in a browser. No build step or network access is required.

The playground demonstrates the same surface through default, loading, empty, error, and success states. Use keyboard Tab navigation to verify that the state controls and action remain reachable. The example intentionally keeps feedback, recovery, and state meaning visible so it can be used as a lightweight review fixture.

For a project review, duplicate the fixture or replace the content with the project's actual states. Record screenshots or manual traversal notes in the project's evidence manifest.
